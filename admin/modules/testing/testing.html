🧪 Testing Utilities

⚠️ Admin Only - Use for testing workflows

Reset Utilities

Use these tools to reset data between testing cycles. Each tool targets a specific system component.

Reset Faculty Points

Reset all faculty bonus points to 0. Base points remain intact.

Clear Service Availability

Delete unavailability requests for SERVICE WEEKS system only.

Clear Moonlighting Signups

Delete moonlighting signups only. Service weeks unaffected.

Clear Service Assignments

Delete generated service week assignments (MICU, APP-ICU, etc).

💣 Complete Reset

Reset everything: points, service requests, moonlighting, assignments.
